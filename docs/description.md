The **Coddle Accessibility Toolkit** is a modern, lightweight web accessibility toolkit by **Coddle Technologies** designed to assist users with disabilities and enhance compliance with WCAG 2.2 Level AA and ADA standards.

### Key Capabilities

- **Accessibility Profiles**: One-click presets for Epilepsy Safe, Seizure Safe, ADHD Friendly, and Low Vision.
- **Text & Reading**: Font scaling (up to 200%), Dyslexia font (`OpenDyslexic3`), highlight titles/links, letter spacing, line height, font weight, and text alignment.
- **Color & Contrast**: Dark Contrast, Light Contrast, High Contrast, High/Low Saturation, and Monochrome modes.
- **Navigation & Tools**: Reading Guide, Large Cursor, Animation Pause, Page Read (TTS), and Sound Mute.
- **Isolated Shadow DOM**: Zero CSS collisions with host themes.
- **Full Keyboard Support**: Global `Option+A` / `Alt+A` shortcut and accessible focus management.
- **Preference Persistence**: Automatic browser storage of user preferences.

### Privacy & Trust Contract

Runs in EmDash's secure workerd sandbox with zero privileged capabilities. No visitor tracking, no external network calls, no data harvesting.
